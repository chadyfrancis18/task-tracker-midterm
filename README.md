# AI-Assisted Coding Final Project

## Project Overview
This repository contains the final project for the AI-Assisted Coding course. The application is a Task Tracker system developed and maintained using AI-assisted workflows, automated testing, and structured documentation.

---

## Final Project Section
The final project showcases the integration of AI tools (such as GitHub Copilot and LLM prompts) across all phases of software development, including code scaffolding, iterative debugging, testing, and comprehensive documentation located in the docs/ directory.

---
